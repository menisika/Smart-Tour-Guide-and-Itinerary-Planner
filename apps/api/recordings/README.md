# Recorded responses

What the replay adapters answer with, instead of calling a language-model or speech service (ADR-0002, ADR-0004, ADR-0027). The format and the way to add a recording are described in [docs/development.md](../../../docs/development.md#recorded-responses).

Everything here so far is a **synthetic sample**, written by hand and marked as such in its `note`. No provider produced it.

Never put into a recording: a key or token, an identifier of a person, a location finer than the city (`NFR-16`).
